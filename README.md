# Scyrox Hub

Standalone Electron-обёртка для веб-конфигуратора мышей Scyrox ([scyrox.net](https://scyrox.net)) с полноценной поддержкой **WebHID**.

Сделано, чтобы не переключаться на Edge/Chrome для настройки мыши, если основной браузер (например, Zen / Firefox) не поддерживает WebHID.

Распаковать в любую папку и запускать `Scyrox Hub.exe`. Установка не требуется.

## Возможности

- **Автовыбор конфиг-интерфейса:** автоматически находит vendor-defined HID-коллекцию (`usagePage: 0xff02`, `reportId: 8`), которую ожидает Scyrox S-Center, и подключает мышь/8K-донгл без лишних диалогов.
- **Модальное окно выбора устройства:** если подключено несколько совместимых устройств (например, мышь по проводу и 8K-донгл одновременно) или ни одного — открывает окно выбора с живым отслеживанием подключения/отключения по USB.
- **Запоминание разрешений:** выданный доступ `(vendorId, productId)` сохраняется в `userData/permitted-devices.json`, поэтому при следующем запуске устройство определяется сразу.
- **Комфортный масштаб:** окно стартует в `1720×980` (под `vw`-верстку `scyrox.net`), запоминает геометрию и поддерживает `Ctrl+=` / `Ctrl+-` / `Ctrl+0` и `F11`.
- **Изолированность:** один экземпляр приложения (`requestSingleInstanceLock`), оффлайн-заглушка при потере сети, внешние ссылки уходят в системный браузер.

## Стек и требования

- Windows 10/11 x64
- Node.js 20+
- Electron 45+

## Запуск и сборка из исходников

```bash
npm install
npm start
```

Сборка standalone-версии под Windows (`dist/Scyrox Hub-win32-x64/Scyrox Hub.exe`):

```bash
npm run build
```

## Горячие клавиши

- `Ctrl + =` / `Ctrl + -` / `Ctrl + 0` — масштаб интерфейса
- `F11` — полноэкранный режим
- `Ctrl + R` / `Ctrl + Shift + R` — перезагрузка (обычная / без кэша)
- `Ctrl + Shift + D` — сброс сохранённых HID-устройств
- `F12` — DevTools
